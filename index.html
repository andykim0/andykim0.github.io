HANFILTER: prompt injection hidden inside documents

github.com/andykim0/hanfilter-poc · Security proof of concept for a CODEGATE 2026 proposal

A deterministic detector for prompt injection hidden inside PDF and DOCX files: white-on-white text, sub-4pt fonts, hidden runs, instructions planted in metadata, zero-width characters, and text rendered off the page. It inspects the structure layer that LLM guardrails never see, because guardrails only receive the extracted text and lose the one decisive signal: this text was hidden on purpose.

  • No model, no API key, runs offline. Every finding carries a reason code, a location, and the recovered text.
  • The DOCX detector resolves the real background behind each run (highlight, run shading, paragraph shading, table cell) before calling text hidden, so white text on a navy header is not a false positive.
  • 31 tests covering all seven reason codes, GitHub Actions CI, an exit-code gate for ingestion pipelines, and a drag-and-drop web demo.

Research

Contextual inverse optimization

Undergraduate research with Prof. Hanasusanto, UIUC Industrial and Enterprise Systems Engineering, Fall 2026

Why does a manager override a planning system's recommended quantity? The project recovers the manager's implicit demand-regime weight and stockout penalty (the newsvendor critical ratio) from records of context, recommendation, and final quantity under a two-regime Gaussian-mixture demand model. Each observation gives a linear equation in the unknowns; with bounded error, linear programs return the feasible set, and four explanations are tested for compatibility. I am building the Python simulator and the identification argument, then running experiments over sample size, noise, and contextual response, with a stress test for false attribution under a binding production limit.
